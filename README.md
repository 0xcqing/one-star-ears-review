A deadpan one-star review of ears, written as a single 102-character line for make.fun's "One-Star Review of Something Essential" bounty. Ears get no off switch, no mute button, and a lifetime subscription to every conversation I did not want; the program writes exactly that line to entry.txt with one trailing newline and verifies the character and byte counts before it exits.
